# Article figures — what each one is

All PDFs here are generated by `../make_article_figures.py` (matplotlib **pgf**
backend, so the fonts are the article's own Computer Modern).  Nothing in this
directory is drawn by hand; every number and curve is read straight out of the
packed run tree `results/bondi-dipole-runaway/`.

Regenerate all of them with

```bash
cd research/bondi_dipole
SCRATCH=/tmp python3 make_article_figures.py      # needs ffmpeg for fig_chase_frames
```

The script also prints, to stdout, every number quoted in the captions and in
the text (grid spreads, control ratios, mirror asymmetry, Weyl growth factors,
wave-zone agreement).

## Data provenance

The quantitative anchor is the **uniform-grid campaign**,
`results/bondi-dipole-runaway/campaign/` — cells `convA_*` (L = 64,
N = 128/192/256, i.e. Δx = 0.50/0.33/0.25) and `boxC_*` (L = 128, N = 256).
The reference configuration is the **separation-12 mixed pair**,
`convA_pm_sep12_n256`.

The older AMR tree `results/bondi-dipole-runaway/data/` is used **only** where
the campaign has no twin: the mirrored pair (`pair_mp_mirror`) and the single
stars.  Those cells run at Δx = 0.5 and are always labelled as such in the
figure itself.

## Drawing conventions

* Grayscale throughout; runs are separated by **line style, not by shade**, so
  the figures survive a black-and-white print.
* Canonical sector Φ₊ = solid, phantom sector Φ₋ = dashed; same-sign controls
  (PP, MM) are the light dotted/short-dashed curves.
* Resolution ladders always use dotted = 0.50, dashed = 0.33, solid = 0.25.
* No unlabelled guide lines: the old vertical t = 30 markers were removed; the
  clean analysis window is stated in the captions instead.

## The figures

### `fig_schematic.pdf` — Bondi's sign rules
Cartoon, no data.  (a) `+ +` fall together, (b) `− −` push apart, (c) `− +`
runs away.  Header states the rule the whole article rests on: each body is
accelerated by the *other's* active mass while its inertia is `|M|` and
positive.  Each row also names what happens to the pair barycentre — fixed in
(a) and (b), accelerating in (c) — which is the quantity every later figure
measures.

### `fig_family.pdf` — the dressed-star family
`stars/star_family.csv`.  ADM mass against frequency ω for both sectors; the
gray band below ω ≈ 0.527 is where no dressed star exists.  Filled stars: the
**reference pair**, both sectors at ω = 0.550 (M₊ = +0.0640, M₋ = −0.0770).
Open star: the **equal-|M| variant**, whose phantom is retuned to ω = 0.566 so
that M₋ = −0.0640.

### `fig_chase_frames.pdf` — the runaway, frame by frame
`campaign/convA_pm_sep12_n256` (Δx = 0.25), movies `scalar_activity_proj_z.mp4`
(top row, 𝒜) and `chi_minus_1_z.mp4` (bottom row, χ−1), at t = 0, 40, 50, 60.
Overlaid: measured sector barycentres (square = Φ₋, circle = Φ₊) from
`sector_barycenters.dat`, dashed ticks at x = ±6 marking the release positions,
thin arrows for the displacement from release, and the measured gap
(12.00 → 11.43 → 11.05 → 10.14).  Both stars move to +x while the gap closes.

### `fig_trajectories.pdf` — worldlines, drifts, gap
Finest campaign grids only.
* **(a)** the two sector worldlines in the reference cell, with the gap
  measured at t = 5, 30, 57 (12.0 → 11.8 → 10.6).
* **(b)** sector drifts Δx: reference d₀ = 12 in black, the contact-inflated
  d₀ = 8 cell in gray dash-dot, PP/MM controls dotted at the bottom.  Curve
  ends are labelled Φ₋ / Φ₊ in the right margin.
* **(c)** the gap d(t), NR against each configuration's own point-mass Bondi
  integration: the model keeps the gap open, the simulation closes it.

### `fig_velocity.pdf` — barycentre velocities
Reference cell, central difference over ±2 time units, against the matched
point-mass model (gray).  Φ₋ reaches v ≈ 0.027 at t = 30 and 0.144 at t = 58;
Φ₊ peaks at ≈ 0.047 near t = 52 before the halo bias drags the tracked centroid
back (see the caveats section of the article).

### `fig_controls.pdf` — the four sign assignments
The "only the mixed pair moves" figure.
* **(a)** pair-barycentre drift at d₀ = 8: `PM` → +6.41, its space-reflected
  twin `MP` → −6.15 (4.7 % asymmetry, both at Δx = 0.5), `PP` and `MM` flat on
  the axis.
* **(b)** the same-sign residuals magnified, with the full resolution ladder:
  PP +0.036 and MM +0.012 at t = 60 — 179× and 545× smaller than the pair,
  both under one cell width of the finest grid, and shrinking with refinement.

### `fig_mirror.pdf` — the mirror test, sector by sector
Same test as `fig_controls` (a) but resolved per star and at fixed numerics:
`data/pair_pm` (lines) against `data/pair_mp_mirror` reflected about x = 0
(markers), both at Δx = 0.5.  Reproduction to ≈ 5 %.

### `fig_convergence.pdf` — the convergence study
* **(a)** the reference cell's resolution ladder in time: the three mixed-pair
  curves lie on top of one another, while the PP control's residual drift
  roughly halves at every refinement step.
* **(b)** the same test read as a refinement sequence — |Δx̄| at t = 60 against
  grid spacing for every family.  Mixed pairs sit on plateaus (spread 0.5 % at
  d₀ = 8, 6.3 % at d₀ = 12, 53 % at the under-resolved d₀ = 16), controls fall
  towards zero.  Note: no formal convergence *order* is quotable, because one
  elliptic solve on a fixed grid feeds all three evolutions and floors the
  constraint violation identically; the grid spread is quoted as an error bar
  instead.

### `fig_weyl.pdf` — the ℓ = 2 Weyl signal
Campaign cells at Δx = 0.25, extraction shell R = 16.
* **(a)** raw r Re ψ₄²·⁰: a monotone chirpless ramp for `PM` against the
  non-secular wander of the same-sign controls.
* **(b)** total ℓ = 2 amplitude, with the equal-|M| run and the `MP` mirror
  overlaid (growth 232× for `PM`, 350× equal-|M|, 122× for the reference
  d₀ = 12 cell).
* **(c)** the amplitude against the rescaled pair speed κ|Ẋ|: correlation
  0.996 with κ ≈ 0.016 — the near-zone quadrupole rises in lockstep with the
  runaway, not with the field frequency.

### `fig_waveconv.pdf` — one outgoing wave in the wave zone
`campaign/boxC_pm_L128_n256` (double box, L = 128).  |r ψ₄²·⁰| on the four
wave-zone shells r = 16/24/32/40 plotted against retarded time u = t − r.
Inside the shaded window u = 10–25 the four shells agree to 1.10–1.40×; before
it they carry start-up junk, after it the expanding matter reaches them.  Open
circles: the half-size L = 64 box at r = 16, differing by 0.07–0.18 % — the
amplitude is box-independent.

### `fig_constraints.pdf` — constraint record (appendix)
Reference cell's full ladder.  (a) Hamiltonian: the three grids' L₂ curves
coincide (the elliptic-solve floor), L∞ for the finest grid, PP/MM controls
under identical numerics.  (b) momentum constraint, L₂.
